# Bevy example

A simple example to show how to use Codira with [Bevy](https://bevyengine.org/).

### How to run?

1. On the CLI, navigate to the `examples/rust-bevy-simple/codira` directory.
2. Run the compiler daemon from the CLI: `/path/to/codira build --watch`
3. Run the application from the CLI: `cargo run -p bevy-simple -- target/mod.codiralib`
