# C++ buoyancy

A simple example to showcase Codira hotloading.

### How to run?

1. On the CLI, navigate to the `examples/buoyancy/codira` directory.
2. Run the compiler daemon from the CLI to run monitor and build the Codira code: `/path/to/codira build --watch`
3. Run the compiled example application from the CLI: `CodiraExampleBuoyancy examples/buoyancy/target/mod.codiralib`
