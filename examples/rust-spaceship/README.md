# Spaceship example

A simple game example

![](screenshot.png)

### How to run?

1. On the CLI, navigate to the `examples/rust-spaceship/codira` directory.
2. Run the compiler daemon from the CLI: `/path/to/codira build --watch`
3. Open another CLI and navigate to the `examples/rust-spaceship`.
4. Run the application from the CLI: `cargo run -p spaceship`
