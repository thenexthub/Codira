# Codira Runtime FFI Bindings

C and C++17 bindings for the Codira Runtime.

## Building

Building requires the Codira library files.
You can specify where those are located by specifying either of the CMake options:

* `codira_binaries_path`: Location of a local directory containing the Codira libraries and executable.
* `codira_library_url`: URL to an archive on the web containing the Codira libraries; e.g. `https://github.com/theomnira/runtime-ffi/releases/download/v0.1.0/ffi-runtime-v0.1.0.tar.gz`.
